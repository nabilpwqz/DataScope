# Mobile Responsive Architecture and Viewport Budget

## Target Viewport: Vivo V23e & Compact Devices (360px - 412px)
- **Minimum Touch Target**: 44px by 44px for primary interactive elements.
- **Drawer Overlays**: Full-width sheet drawer with bottom padding to prevent system navigation bar collision.
- **Horizontal Scroll Containers**: Data table supports fluid horizontal touch scrolling with sticky record keys.
- **No Forced Horizontal Overflow**: Control bars wrap into vertical stacks on viewports < 640px.
